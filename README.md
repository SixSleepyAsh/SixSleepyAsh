### Things I've built

**[Project Eternum Engine](https://github.com/Singularity-Works/Project-Eternum-Engine)**
A roguelike engine written from scratch in C++20. Procedural dungeons, three pathfinding algorithms, a terminal renderer that does not flicker, and 287 tests.

**[Dig Deeper](https://github.com/Oblivion-Owls-Inc/Project-OWL)**
A 2D tower defense exploration game on a custom C++ engine, built by a team of ten at DigiPen. I produced it, wrote the editor, and composed the soundtrack.

**[Playtest telemetry](https://github.com/SixSleepyAsh/playtest-telemetry)**
The ingest service my card game uploads to. A self hosted Node receiver and a Cloudflare Worker fallback, no dependencies, running with real playtest data in it.
